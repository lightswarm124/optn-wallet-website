# OPTN Labs Content Map

Drafted March 8, 2026.

## Positioning

OPTN Labs should present itself as a BCH infrastructure and engineering company with three connected offers:

1. A wallet product that proves UX patterns in the real world
2. Hosted infrastructure access for teams that do not want to run all BCH plumbing themselves
3. Hands-on engineering support for CashTokens, covenant flows, and production launch work

The site should not read like a generic crypto landing page or a wallet download page. It should read like a focused company site for teams building on Bitcoin Cash.

## Primary Audience

- Founders and technical leads evaluating BCH for a product launch
- Teams already building on BCH that need better infrastructure or integration support
- Developers researching CashTokens, covenant UX, token metadata, and transaction reliability

## Core Message Hierarchy

1. OPTN Labs helps teams ship serious BCH products
2. The company has something real today: wallet, hosted access, engineering support
3. The team is specifically strong in CashTokens, covenant-oriented flows, and operational reliability
4. There is a clear path to engage: read updates, evaluate products, request access

## Homepage Goals

- Explain what OPTN Labs does in one screen
- Show what is live now
- Separate the three offers clearly
- Show concrete use cases and buyer fit
- Create trust with updates, source code, and dated milestones
- Convert visitors into inquiry emails or product evaluation actions
